# duolingo-solver
Have you ever had a teacher assign you work for duolingo and you don't feel like doing it, or you're low on hearts and need to finish your lesson? This is perfect for you!
# System Requirments
A good enough computer to run a AI Model locally
At least 10 GB free of storage to install the local AI Model
Enough ram and VRAM for fast responses.
# How to use
1. Download the python file linked.
2. Download and install Python 3 at https://www.python.org/downloads/
3. Install Ollama at https://ollama.com/download
4. Install extentions, in the command prompt or Powershell enter the following command pip install ollama pyautogui pillow
5. Install Qwen3-vl:8b, Open command prompt or Powershell and enter the following command. ollama pull qwen3-vl:8b
6. Choose the location of where the screenshots are placed. Default is set to C:\Duolingo-Solver\duolingo.png,
7. Run the Python application
8. Hop over to your Duolingo lesson and let it work.
Please keep in mind that this is a WIP and is still being worked on, thats why it does not auto press check.
